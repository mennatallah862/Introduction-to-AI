## 📌 About This Repository

Welcome to the **Introduction to Artificial Intelligence** practical repository at **Beni Suef National University**.

This repository is specifically created to organize and share practical lab materials, code examples, exercises, and related files used throughout the lab sessions.

All materials will be uploaded and organized as the semester progresses, making it easier for students to access, review, and practice the concepts covered in each session.

## 📥 Getting Started

To download the repository, run:

```bash
git clone https://github.com/mennatallah862/Introduction-to-AI.git
```

Replace `YOUR-USERNAME` with the GitHub username that owns the repository.

Alternatively, click **Code → Download ZIP** on the repository page.
